# Birmingham City University LaTeX Template

A LaTeX template for Birmingham City University coursework, reports, projects, and dissertations.

This template is based on an original template provided by BCU academic staff and has been further developed with additional features, including:

* Dissertation and report layouts
* Bibliography support
* Multiple referencing styles

Credit for the original template belongs to the BCU lecturers who created and distributed it. This repository contains enhancements built upon their work.

This template is provided free to use, modify, and distribute. It is not officially affiliated with or endorsed by Birmingham City University.
